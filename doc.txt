================================================================================
 🤖 Getting Started Guide: Qwen Code CLI v2.0 (Claude Code Style)
================================================================================

Welcome to the 100% local, secure AI Coding Agent running directly on your machine.
Equipped with streaming responses, smart autocomplete, surgical code patching, and git integration.

--------------------------------------------------------------------------------
📌 Setup and Launch Steps (Starting from VS Code)
--------------------------------------------------------------------------------

1. Open the project folder in VS Code:
   - Go to File > Open Folder... and select the 'qwen-cli' directory.

2. Open the built-in Terminal in VS Code (Press Ctrl + `).

3. Start the system components using two terminal sessions:

   -------------------------------------------------------------------------
   🖥️ Terminal 1: Run Local LLM Server (Keep this running in the background)
   -------------------------------------------------------------------------
   Run the split GGUF model in the models folder:
   
   python -m llama_cpp.server --model models/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf --port 8080 --n_ctx 2048 --verbose False

   -------------------------------------------------------------------------
   💻 Terminal 2: Run Qwen Code CLI Chat Window (Your interactive workspace)
   -------------------------------------------------------------------------
   Open a new terminal window or split the current one, then activate the environment
   and run the main script:

   source venv/bin/activate
   python3 qwen-code-cli.py

   (Alternatively, use the one-liner command: venv/bin/python qwen-code-cli.py)

-------------------------------------------------------------------------
📖 Slash Commands
-------------------------------------------------------------------------
While running the CLI, you can input the following slash commands directly:

  /help        - Display this guide and all commands
  /clear       - Clear the terminal screen
  /reset       - Clear conversation history (starts a fresh session to save context memory)
  /tools       - List all tools the agent can use to perform tasks
  /context     - View the contents of .qwen-context.md (project overview)
  /tree        - Print the current directory structure as a file tree diagram
  /git         - Check basic git status and the last 10 commit logs
  /diff        - [NEW!] View color-coded git diff preview of modified files
  /commit      - [NEW!] Let LLM write a commit message based on diff and execute commit
  exit / quit  - Safely exit the application

-------------------------------------------------------------------------
✨ Notable Upgraded Features (Claude Code-aligned)
-------------------------------------------------------------------------

1. Smart Autocomplete:
   - When viewing files, changing directories, or typing slash commands, the UI provides
     tab-completion to guess matching files, directories, or commands.

2. Line Range Reading (Partial Reading):
   - To optimize token usage and speed up processing 3x-5x, the file reader allows
     specifying start and end lines: `view_and_read_file(file_path="xyz.py", start_line=1, end_line=50)`

3. Real-time Command Output Streaming:
   - Output from bash commands (e.g. running tests or installing packages) streams directly to
     your terminal window live, and you can stop execution at any time using Ctrl+C.
