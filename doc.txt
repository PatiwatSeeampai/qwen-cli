================================================================================
 🤖 คู่มือเริ่มต้นใช้งาน Qwen Code CLI v2.0 (Claude Code Style)
================================================================================

ยินดีต้อนรับสู่ระบบ Local AI Coding Agent ที่รันบนเครื่องของคุณเองแบบ 100% ปลอดภัย 
มาพร้อมระบบ Streaming, Smart Autocomplete, surgical patch, และ Git Integration

--------------------------------------------------------------------------------
📌 ขั้นตอนการเริ่มต้นใช้งาน (เริ่มจาก VS Code)
--------------------------------------------------------------------------------

1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code:
   - ไปที่ File > Open Folder... เลือกโฟลเดอร์ 'qwen-cli'

2. เปิดใช้งานหน้าต่าง Terminal ใน VS Code (กดปุ่ม Ctrl + `)

3. ทำการเปิดใช้งานระบบตามหน้าต่าง Terminal ดังนี้:

   -------------------------------------------------------------------------
   🖥️ หน้าต่างที่ 1: รัน Local LLM Server (เปิดทิ้งไว้เพื่อเป็นสมองของ AI)
   -------------------------------------------------------------------------
   พิมพ์คำสั่งรันโมเดลที่ถูกแบ่งส่วน (Split GGUF) ในโฟลเดอร์ models:
   
   python -m llama_cpp.server --model models/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf --port 8080 --n_ctx 2048 --verbose False

   -------------------------------------------------------------------------
   💻 หน้าต่างที่ 2: รันหน้าต่างแชท Qwen Code CLI (หน้าจอสำหรับพิมพ์สั่งงาน)
   -------------------------------------------------------------------------
   เปิด Terminal อีกหน้าต่างขึ้นมาคู่กัน (กดยื่นปุ่ม '+' หรือ Split Terminal)
   แล้วพิมพ์คำสั่งเพื่อเรียกทำงานสคริปต์หลัก:

   source venv/bin/activate
   python3 qwen-code-cli.py

   (หรือใช้คำสั่งทางลัดบรรทัดเดียว: venv/bin/python qwen-code-cli.py)

-------------------------------------------------------------------------
📖 คำสั่งพิเศษ (Slash Commands)
-------------------------------------------------------------------------
ขณะรัน CLI คุณสามารถพิมพ์คำสั่งพิเศษด้านล่างนี้ได้โดยตรงในหน้าต่างแชท:

  /help        - แสดงคู่มือและคำสั่งพิเศษทั้งหมด
  /clear       - เคลียร์หน้าจอ Terminal
  /reset       - ล้างประวัติการแชท (เริ่มเซสชันใหม่เพื่อประหยัดความจำโมเดล)
  /tools       - แสดงรายชื่อเครื่องมือทั้งหมดที่ Agent ใช้ทำงานได้
  /context     - ดูเนื้อหาไฟล์ .qwen-context.md (บันทึกข้อมูลภาพรวมของโปรเจกต์)
  /tree        - แสดงโครงสร้างไฟล์ของไดเรกทอรีปัจจุบันในรูปแบบแผนผังต้นไม้ (Tree)
  /git         - ตรวจดูสถานะ Git เบื้องต้นและประวัติการ commit ล่าสุด 10 รายการ
  /diff        - [ใหม่!] แสดง Git Diff ของไฟล์ที่มีการเปลี่ยนแปลงล่าสุดแบบใช้คู่สี
  /commit      - [ใหม่!] ให้ LLM แต่ง Commit Message ตาม Diff ปัจจุบันให้ และช่วย Commit ให้ทันที
  exit / quit  - ออกจากการรันโปรแกรมอย่างปลอดภัย

-------------------------------------------------------------------------
✨ ฟีเจอร์เด่นและเครื่องมือที่อัปเกรดใหม่ (Claude Code-aligned)
-------------------------------------------------------------------------

1. ระบบแนะนำคำอัจฉริยะ (Smart Autocomplete):
   - เวลาที่คุณจะเปิดไฟล์ เปลี่ยนโฟลเดอร์ หรือเรียกคำสั่งพิเศษ ระบบจะมี Tab-completion 
     คอยเดาชื่อไฟล์ โฟลเดอร์ หรือคำสั่งขึ้นมาให้พิมพ์สะดวกยิ่งขึ้น

2. การอ่านเฉพาะช่วงของไฟล์ (Line Range Reading):
   - เพื่อประหยัด Token และทำให้โปรแกรมรันได้เร็วขึ้น 3-5 เท่า เครื่องมืออ่านไฟล์สามารถเลือก
     ระบุบรรทัดที่ต้องการได้ เช่น 'view_and_read_file(file_path="xyz.py", start_line=1, end_line=50)'

3. แสดงผลรันคำสั่งแบบ Real-time (Command Output Streaming):
   - ทุกครั้งที่สั่งรันคำสั่ง Bash เช่น รันเทส หรือติดตั้งแพ็กเกจ CLI จะสตรีมผลลัพธ์ลงหน้าจอทันที
     แบบสดๆ ทำให้คุณไม่รู้สึกว่าคอมค้าง และคุณสามารถกด Ctrl+C เพื่อสั่งหยุดการทำงานได้ทุกเมื่อ
